Implement build_order(deps) in build.py. `deps` maps each target to the targets it depends on (a dependency may not appear as a key). Return an order where every target comes after its dependencies; among targets that are ready at the same time, pick them alphabetically. If there is a cycle, raise CycleError whose `cycle` attribute is the cycle as a list that starts and ends with the same target, e.g. ["a", "b", "a"].
